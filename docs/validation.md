## 本轮修正

Windows 的 `lstat` 与 `fstat` 创建时间字段可能不同，原快照工具将未修改文件误判为变化；现在跨 API 比较文件身份、大小和修改时间，创建时间分别在同一 API 的读取前后核对。新增两个回归测试覆盖正常差异与读取中变化，保留修改检测。

Windows `DirEntry.stat` 的硬链接数字段为 0，原清单检查将普通文件误判为不安全；改用 `Path.lstat` 读取真实链接数，继续拒绝符号链接、重解析点和多硬链接。

编码测试的子进程环境改为系统启动和临时目录相关变量白名单，避免复制与测试无关的环境变量。没有新增第三方运行依赖。
