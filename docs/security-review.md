## 文件与隐私

- 模板 8 页、25 个 OOXML 部件均为通用文字与原生形状／表格；没有作者属性、备注、评论、图片、媒体、嵌入文件、外部关系或宏部件。
- 模板预览已目视检查；JPG 没有 EXIF，仅有 JFIF 基本信息，没有姓名、定位或设备标识。
- 本轮保留模板和预览原始哈希，没有将个人原稿或真实案例混入发布包。
- 文本中的公开文章来源与作者归属是来源信息；合成路径和负向测试字符串不是用户私人文件。

## 使用边界

`audit_pptx.py` 会在报告中返回输入路径和发现问题的文字片段；这些是任务资料，报告应保留在私有工作目录，分享前核对内容。`freeze_review.py` 仅根据显式文件清单创建新目录，拒绝覆盖、路径穿越、符号链接／重解析点和多硬链接；中途失败会留下不完整结果用于排查，不自动删除。它要求稳定私有目录，不提供对恶意并发写入者的操作系统级隔离。

静态扫描与源码审查不能证明所有输入、Python 版本或宿主工具安全；本轮未执行真实政治主题演示、账号登录、媒体下载或外部上传。
