# 逐页内容与分区计划

在S04使用，S05渲染验证，S06自检与独立审查分别复核。先决定“这页要说清什么”，再决定形状和位置；不要先画满卡片再找句子填入。

## 1. 分开判断两个问题

- **内容充分性**：页面是否用具体材料回答了主问题，并让读者看出材料为何支持结论。字号大、句子多或讲稿长都不等于充分。
- **空间与分区**：已选内容是否按真实关系组织，主次、边界和阅读顺序是否可见。内容充分的页也可能拥挤、散乱或主次倒置。

实质正文页需要可见的“主问题／答案 → 具体支撑 → 必要解释”。可以用文字、标注图片、原生表格或图解共同完成，不必各占一块。主问题可写成结论式标题；计划里的claim_id不必上屏。

备注补充背景、旁证、展开讲述与过渡，不必把全部讲稿搬上屏；但支撑本页结论、避免误读所必需的事实、范围／口径和对象对应关系不能只藏在备注。先补缺失的有效材料，再改善分区；若材料不足，回到来源阶段，或在不删必需内容的前提下合并页面。不能编造、重复、放大口号或加无关图片来显得饱满。

## 2. 每页先填写一行计划

记录：页号与页型；主问题；一句答案；拟上屏的具体证据及claim_id／媒体；解释证据与答案的关系；信息分组关系；区域角色与阅读顺序；承接页与口播预算。

“区域角色”写内容作用，如背景、主证据、对照、解释、归纳；再写位置、相对主次、边界方式和间距。没有关系的材料不因字数相近而放成同级；只有标题不同、正文重复的块应合并。区域数量由内容决定，不设最少框数。

中性示例：一页回答“服务流程调整解决了什么问题”。用经核验的原有环节、改变动作和结果支撑；流程作主区，结果紧邻对应步骤，必要条件作次区。不要把“背景、动作、结果”做成三个同权大数，也不要把仅在讲稿中出现的结果算作已上屏。

## 3. 按页型选择内容与关系

| 页型 | 上屏应完成的任务 | 适用组织方式 |
|---|---|---|
| 解释／概念 | 给出含义、具体组成或表现，以及为何得出本页结论 | 总分、解释＋例证；不是几条同义口号 |
| 事件／案例 | 交代必要背景、关键动作／事实及结果或意义；不支持的因果不补写 | 图文、经过→结果、案例＋解释 |
| 对照／分类 | 明确比较维度或分类依据；区分上位类别、实例与补充材料 | 原生对照表、分层分组；不同层级不并列 |
| 数据 | 让读者先知道“什么指标”，再读数值、单位、期间、范围及含义 | 可比数据用图表；不可比指标分主题解释，不伪装成同口径排名 |
| 历程／流程 | 展示真实时序、步骤、转折或依赖，并说明关键节点 | 时间线、原生流程；箭头必须有时间、方向或依赖含义 |
| 综合／归纳 | 汇总已展示的具体依据，说明它们的联系和本页答案 | 证据到结论、关系图、归纳表；不另起无证据口号 |

封面、目录、章节过渡、结束页按各自导航或收束任务验收，可有意留白。引语页保持原意、归属及必要语境，不强行扩写；若承担解释任务，关键解读仍须可见。视频页以真实视频、观看问题和时长为主，不因静态文字少判内容不足。不要将上述页型当作整稿正文的代表样页。

## 4. 把语义关系做成可见分区

1. 保留认可模板的外框、配色、字体与受保护元素，按design.md选择最适合的正文布局。
2. 让本页主问题／答案成为正文阅读入口。章节条只作导航；不在主体再次堆叠同义标题挤掉证据。若受保护模板本身造成冲突，记录并请求必要决定，不擅自改母版。
3. 把同一对象的标题、事实、图注和解释放近，统一对齐。用暖浅底、细线、对比或成组留白标明边界，不要求每区都有框。
4. 按信息量和重要性分配宽高与内边距。组内间距通常小于组间间距；不要把长短悬殊的内容强塞等高盒，也不要让说明远离对应图或数字。
5. 图片说明真实对象及与问题的关系；表格用于比较，图解用于解释关系。没有对应任务的照片、图标、箭头或空框不算信息。

## 5. 渲染后的两个出口

- **内容出口**：指出画面中具体哪一项回答问题、哪一项支撑答案、哪一项说明关系。只指向备注、泛化结论或重复句子，则未通过。
- **分区出口**：指出首读位置、各区角色及连接关系，并在实际渲染中看见主次、边界、对齐和足够间距。只说“分了三块”或“很饱满”，则没有验证证据。

两项分别记录pass／fail／unverified及页面位置。字数、字符数、填充百分比、形状数量和备注长度不能替代判断；稀疏本身不等于失败，装满也不等于通过。
