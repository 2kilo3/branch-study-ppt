# 九阶段执行协议

所有产物保存在当次获授权的工作目录。以下文件名为建议，可改变，但每条引用必须指向真实存在、版本匹配且执行者可读的文件。先复制 `../assets/run-state-template.json`，再填入实际值；模板中的pending不是已执行证据。

状态：`pending`未开始；`running`进行中；`passed`有证据满足出口；`failed`已发现不符合；`blocked`缺输入／权限／能力；`reused`复用且完成本轮影响检查。仅passed或有完整复用证据的reused能产生阶段DONE标记。审查单项另用pass／fail／unverified／not_applicable，blocked原因记录在unverified项中。必需项不得用not_applicable跳过。

## S01 需求与基线
- **Inputs**：本轮用户请求、可用文件、真实日期与时区、实际能力。
- **Actions**：记录新建／整体修订／局部修改／仅讲稿模式；确定范围、受众、媒体、时长、交付目标、保护部分和必需验收环境。主题未指定时将阶段2设为学习强国时事选题。列出所需能力是否可用，按[toolchain.md](toolchain.md)选择至少一条当前可执行的制作、渲染和媒体路径；没有必要不重复造工具链或安装软件。用户提供认可模板时记录版本与校验值；没有则使用design.md，不声称复用了原始模板。
- **Constraints**：不猜组织名、人物身份或原稿内容。细节可暂定并注明；缺少事实、关键权限或必需能力不能以假设代替。局部修改不扩大范围。
- **Outputs**：brief、baseline清单、能力清单、run_state。
- **Done**：范围与验收要求无未解决冲突，关键输入足够，保护部分清楚。标记`S01_DONE`。
- **Blocked**：写明缺什么、影响哪一步、需要用户提供什么；只暂停依赖该缺口的工作。

## S02 官方来源与时效
- **Inputs**：S01产物；实际可用的网络检索、正文读取／获准渲染浏览能力，或已提供的完整文章材料。
- **Actions**：先学习强国选主题与主文章，形成主体内容，再用新华网、央视网及正式官方来源补充、交叉核验或追溯。实际打开全文，记录检索日期、范围、关键词、URL、标题、发布主体、承载平台。分别核对原始发布、转载、事件、数据期间和更新／生效日期。对“当前、最新、现任、已完成”查询后续版本和更正。检索不可靠、页面无正文或访问失败时，按[source-recovery.md](source-recovery.md)识别故障层、取得真实详情URL，再选择有证据支持的恢复路径。
- **Constraints**：摘要、域名和搜索未命中不是事实证据。年度数与阶段数不能按网页新旧互换。旧材料可作准确标明的历史背景。没有学习强国主体材料时，不悄悄把补充来源升级为主源。
- **Outputs**：来源访问记录、已读取原文的定位或必要短摘录、动态事实适用性记录；发生恢复时另记实际尝试、全文完整性、source_status、主源要求是否满足及未解决缺口。
- **Done**：主题和关键材料可追溯，最新适用判断有查询范围与日期。标记`S02_DONE`。
- **Blocked**：经过当前可用且获准的实质不同路径仍缺必需主源全文，或关键事实冲突未解，标为unverified并给最小解阻问题。页面标题、首段、摘要或另一官网可读不等于主源恢复。可继续不依赖缺口的已授权版式／条件式时长工作，但不定稿依赖事实页、不伪标阶段DONE；可删除非必需且不影响目的的主张，不能编造、绕过访问限制或未经明确批准替换主源。

## S03 主张台账与媒体
- **Inputs**：S02证据、拟用图片与视频。
- **Actions**：对标题、正文、图表、图注和讲稿拟用的独立事实建立台账。相同事实可复用证据，但逐处检查措辞。台账记录claim_id、slide_id、原句／类型、原始URL、发布主体／平台、证据定位、各类日期、单位／分母／范围、适用性、verified／unverified／removed及原因。图片按稳定asset_id、文件哈希、真实对象、来源、使用限制与目标页绑定，用带ID的预览核对，不按批量返回顺序猜。视频记录关联、来源、方式、文件或URL、实际片段、时长及验证层级；按[media-workflow.md](media-workflow.md)核验实际台标/片尾归属，不从网页通用页脚推断出品方。
- **Constraints**：生成图或示意图不得冒充新闻现场。只能按获准方式使用媒体；无下载权限不绕过。视频必须有真实内容，不能只有占位框。未知时长不记为实测。
- **Recovery**：视频下载／嵌入受阻时按[source-recovery.md第6节](source-recovery.md#6-视频获取受阻时)核对本轮范围、记录实际失败并检查其他合适官方候选；具体制作请求已涵盖的普通公开素材获取，在宿主允许范围内直接执行，不反复确认。需要新安装／登录／权限、付费或确实缺授权时单独处理；改在线链接须确认，不直接取消必需视频。
- **Outputs**：source-claim-ledger、media-manifest、可合法使用的素材。
- **Done**：拟保留事实有可追溯支持，媒体齐备且使用方式明确，无未处理的关键核验缺口。标记`S03_DONE`。
- **Blocked**：列出缺失或不可使用媒体、事实及所需条件；不将待核验说法无保留写入整稿。

## S04 叙事大纲与时长
- **Inputs**：brief、台账、媒体时长。
- **Actions**：先读[timing.md](timing.md)，用plan_timing.py根据本轮视频和预留求可行字数区间，再读[page-planning.md](page-planning.md)，逐页记录页型、主问题、答案、拟上屏具体证据及claim_id／媒体、必要解释、分组关系、区域角色与阅读顺序、承接关系及口播预算。先分配必需视频时间，再分配口播。明确主体＝口播＋视频；现场＝主体＋切换／停顿／互动。未知语速时可用230—250汉字／分钟估算，标明数字、英文和停顿的误差，并计划排练校准。
- **Constraints**：默认主体40—45分钟，同时将切换／停顿／互动预留在45分钟现场上限内；通常主体安排40—42分钟，再分配余量。用户明确其他上限时重分配；若要求无法同时满足，说明冲突，不隐瞒超时。不得重复凑时长、固定25页／两段视频，或为按政治身份改变受众态度设计叙事。因果和时间关系必须成立。
- **Outputs**：逐页内容与分区计划、分项时长预算及假设。
- **Done**：每张实质正文的答案有拟上屏的具体支撑与解释，分组有真实关系；非正文页的功能与留白理由明确。关键事实不能只列在备注计划中。目标区间可行，窗口宽度与余量明确；先在独立讲稿中计数和调整，再批量写入PPT，避免每次改字都重建。没有可靠依据不得收窄语速、擅删互动或延长无关视频来通过。估算不冒充排练。标记`S04_DONE`。
- **Blocked**：时长或素材不足，返回上游补充／精简有效内容，不靠空话或装饰填充。

## S05 代表页模板适配
- **Inputs**：大纲、认可模板（若有）、design.md、可编辑制作及渲染能力。
- **Actions**：优先选解释链最长、材料层级最多或最难布局的实质正文，覆盖本轮实际使用的解释、案例、数据／对照、流程等不同关系；同页可覆盖多项。不用封面、章节、引语或视频页替代正文样页。记录选页理由并用真实内容适配、渲染，逐页执行page-planning.md的内容与分区两个出口，另查字体、换行与裁切。无原模板时按design.md实现风格，不能称为原稿复用。
- **Constraints**：已有认可模板时保留它，不擅自重设计。正文默认≥20pt，图注约18pt需可读。先删冗余、拆页或换布局，不先缩字。不设页面填充率。
- **Outputs**：代表页、渲染图、选页覆盖理由、双项出口证据及适配记录。
- **Done**：每类高风险正文均有通过的代表页，能从渲染中指出具体支撑、主次与区域关系，且可读、可扩展；失败先回改计划或样页，不批量复制失败布局。标记`S05_DONE`。仅用户要求看样时等待看样，不额外引入逐页审批。
- **Blocked**：无法渲染、中文缺字或无法编辑，记录能力缺口，不只检查源代码即宣布通过。

## S06 全稿与自检
- **Inputs**：已通过代表页、全部内容、素材、台账。
- **Actions**：制作候选PPTX及逐页自然口播。按实际放映顺序导出全页渲染和备注，隐藏页另列。逐页分别记录内容充分性与空间分区的结论和画面证据；对照备注找出只在讲稿中出现的关键支撑，并检查是否误把不同关系套成同款卡片。另查核心对象可编辑、中文字体、图文一致、内部关系、视频、时长及保护部分。用下述辅助脚本生成绑定候选SHA-256的审计JSON；页数、字数、分项估算以该测量为计算依据，其他文档引用而不手写重复数值。脚本不可用时须记录替代测量方法与文件版本，不伪造结果。
- **Constraints**：不要用整页截图代替可编辑PPT。页面通常无来源串，必要归属和限定仍保留；讲稿无来源、计时、操作标签。云端渲染、媒体解码、目标PowerPoint播放分别记录。
- **Outputs**：candidate.pptx、全页渲染、page-order、notes导出、逐页双项检查及其他作者自检原始证据、更新台账与媒体清单。
- **Done**：产物版本匹配、可打开，全页实际查看；无已知但未记录的重大问题。标记`S06_DONE`，不等于独立验收完成。
- **Blocked**：关键渲染、媒体或编辑性失败时先修复；可交给审查者诊断，但不得宣称阶段已通过。

## S07 隔离独立审查
- **Inputs**：S06证据包、固定验收标准、review.md及reviewer-prompt.md。
- **Actions**：先按[review-control.md](review-control.md)冻结显式证据文件到新目录、保存manifest摘要并验证；再创建不继承作者对话的全新审查上下文，仅交接可信用户要求和实际证据。审查者从PPT及备注自行建立完整内容清单、独立打开来源、逐页审阅、提交可复核问题。记录实际隔离方式、冻结快照、清单摘要和报告；报告在快照外保存，审查前后复验快照，不边改在审文件边宣称结论有效。
- **Constraints**：不交接作者自评、预期评级或通过保证；作者台账不是事实保证。上下文独立不等于无遗漏，也不要求一定换模型。
- **Outputs**：独立报告、逐页覆盖、主张核验记录、问题清单。
- **Done**：审查实际执行、覆盖必需维度、每项结论有证据。标记`S07_DONE`；审查发现问题不妨碍进入修复，但不代表PPT可交付。
- **Blocked**：无真正隔离能力，记“独立审查未完成”；不能把作者换角色自检改名为独立审查。

## S08 修复与独立复审
- **Inputs**：独立问题清单及候选版本。
- **Actions**：先修事实、缺失、缺字溢出、媒体、时长等实质问题，再修其他明显缺陷；保留新版本、差异及新证据。按[review-control.md](review-control.md)确定复审范围：局部视觉查改动页及受影响邻页；事实变化查所有出现位置和关联来源；字体、母版、页序等全局变化查全部受影响页面。已独立核验且未变化、未失效的证据可保留并标复用，不每轮无差别重开全部来源。每次新候选重新测量和冻结。
- **Constraints**：作者不得自己关单，不能只删台账中的失败主张而让画面／讲稿仍保留；不能删除必需内容或降低标准求通过。越过保护范围须先询问。
- **Outputs**：修订PPTX、更新的渲染／备注／台账、问题闭环表、独立复审报告。
- **Done**：所有必需项pass，阻断／重大问题凭新证据关闭，无影响验收的unverified。若无问题，记录无需修复及独立证据。标记`S08_DONE`。
- **Blocked**：同一问题反复未解决时升级根因诊断，分清规范、内容、代码、工具、环境、权限和观察能力；不能按固定两轮自动判环境问题。缺条件时列精确阻塞，不无限重试或换审查者求通过。达到标准后不为个人偏好无限返工。

## S09 最终验收与授权交付
- **Inputs**：已通过独立验收的最终版本、交付授权及目的地。
- **Actions**：以校验值或明确版本核对交付文件就是已审文件；核对页序、备注、媒体、台账。报告主体／现场时长、重要变化、实际审查和兼容性边界。按授权交付，检查实际返回结果与最小权限；制作状态、审查状态和交付状态分别记录。
- **Constraints**：按[media-workflow.md](media-workflow.md)分别记录启动/声音/seek冒烟、整段播放和排练；只捕获必要PPT窗口，不能把整屏无关内容当验收证据。未实测桌面放映不得称通过；若其为必需项则验收未完成。可按用户授权交付待补验证候选并附最小补测清单，标candidate_ready_for_user_validation，不标S08/S09_DONE或overall_status=completed，也不写“无阻塞”。无授权不上传、外发、公开分享、覆盖或删除；不擅自改公开链接或分卷。
- **Outputs**：最终PPTX、台账、媒体与操作说明（不混入口播）、独立结论、run_state及交付证据。
- **Done**：最终文件与报告一致，授权交付成功且可访问。标记`S09_DONE`，`overall_status=completed`。
- **Blocked**：缺交付授权或上传失败则文件可为ready，但delivery为blocked／not_attempted；不能把本地生成说成已上传。

## 前置时长与候选结构检查

讲稿成稿前按[timing.md](timing.md)运行plan_timing.py；它不需要PPTX。视频720秒/预留120秒只是已验证算例，实际任务必须用本轮数值。预算不可行时先调整有依据的条件，不重建PPT凑字。

候选完成后：

在本轮获授权工作目录中执行；下例假设技能文件夹位于该目录内，其他位置须填写实际脚本相对路径。参数须替换成真实的全稿视频总秒数和切换／停顿预算。例中的120和45仅演示参数，不是推荐视频时长或验收证据：

```sh
python -B -X utf8 branch-study-ppt/scripts/audit_pptx.py candidate.pptx --min-font 20 --rate-min 230 --rate-max 250 --video-seconds 120 --transition-seconds 45 > audit.json
```

脚本仅使用Python标准库，不联网、不下载依赖、不修改PPTX。旧`timing_estimate.total_minutes`含切换预算，表示现场而非主体。优先读新speech/body/session分项和timing_budget目标区间、差额及count_basis；它们仍是基于输入与汉字代理数的估算。input_fingerprint将测量绑定到候选字节；冻结前核对一致。脚本按全部列出页计数，含隐藏页；正式时长须按实际播放范围重算。无视频默认值0只供结构检查，不满足本技能的媒体要求。

它检查显式字号、部分形状边界、内部目标存在、备注汉字计数。它不检测内容是否回答问题、证据是否上屏、语义分组或区域主次，也不证明有效继承字号、全部溢出／遮挡、来源准确、链接可访问、媒体播放、字体兼容或视觉通过。退出0是成功输出报告，非PPT通过。可在技能目录用 `python -B -X utf8 -m unittest discover -s scripts -v` 验证合成夹具单元测试；测试会在临时目录创建并删除合成文件，不使用用户原稿，不等于完整试跑。输出按UTF-8解码；重定向须保持字节或明确使用UTF-8，详见[runtime.md](runtime.md)的父子进程、shell和缓存边界。

## 状态例子与禁止的捷径

- 已完成：`S06_DONE`，证据为同一候选版本的全页图、逐页检查记录、备注和对象检查结果。不能只写“已看过”。
- 未验证：源文件有视频关系，但未播放，填`media_playback=unverified`；不得写“视频正常”。
- 未执行：只修改技能文档，填`end_to_end_test=not_run`；不能称九阶段跑通。
- 已阻塞：环境无新上下文能力，停在S07并列出所需能力；不能用自检冒充独立审查。
- 已复用：局部修改不影响旧来源时，记录旧证据版本、验证日期及本轮影响检查；不是重新查证。

完整试跑／回测另需明确授权，使用隔离输出目录、真实输入与全部九阶段证据。不得预填成功；单元测试、脚本通过和技能阅读都不是端到端验证。本包不附带已经完成的试跑结果。
